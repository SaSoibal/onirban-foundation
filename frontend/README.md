# Onirban Foundation - Frontend

React 18 + Vite frontend for the Onirban Foundation.

## Features

- React Router with HashRouter for GitHub Pages
- Axios with Sanctum token interceptor
- Tailwind CSS styling
- React Hot Toast notifications
- Responsive public pages and admin panel

## Requirements

- Node.js 20+
- npm 9+

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Test

```bash
npm test
```

## Deploy

Frontend is deployed to GitHub Pages via GitHub Actions.

## Environment Variables

```
VITE_API_BASE_URL=https://api.onirban-foundation.railway.app/api
VITE_APP_URL=https://sasoibal.github.io/onirban-foundation-
```
